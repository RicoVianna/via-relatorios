## 1. VISÃO GERAL E STACK

- **Produto:** PWA para corretores de imóveis gerarem laudos de vistoria em PDF (mobile-first).
- **Stack:** Next.js 16.2.12 (App Router + Turbopack), TypeScript, Tailwind CSS, Supabase (Auth + Postgres + Storage), `@react-pdf/renderer` (PDF no cliente), Gemini (IA de texto).
- **Repo:** GitHub `RicoVianna/via-relatorios`. Rodar: `npm run dev` → `http://localhost:3000`.
- **Estrutura de rotas:** grupos `(auth)` (login/cadastro), `(dashboard)` (telas logadas), rotas dinâmicas `[id]`.
- **Usuário/desenvolvedor:** dono do produto, nível iniciante em imagens/CSS, confortável com terminal/PowerShell. Prefere MVP, sem "perfumaria".

## 2. IDENTIDADE DA MARCA (decisões fechadas)

- **Símbolo aprovado:** casa em traço com check integrado, verde + grafite + filete dourado interno. Arquivo-fonte: `Downloads/logo-original.png` (1664×928); ícones gerados por recorte quadrado central.
- **Paleta operacional (usada em código):**
    - Fundo splash/dark: degradê `#1B211B → #2C3A2C`
    - Off-white (cards/claro): `#F6F5F1`
    - Dourado discreto: `#C2A24B`
- **Regra de uso do logo:** sempre dentro de card off-white arredondado sobre fundos escuros; wordmark "VIA RELATÓRIOS" como tipografia (não embutir texto em ícones).
- **Transições:** páginas entram com fade+subida (`vrPageFade` no `globals.css`); splashes com fade.
